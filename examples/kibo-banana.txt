# Name: Kibo is going Bananas
# Owner: Sam
# Kibo, Uktabi Prince — Gruul Ape typal, imported from
# https://archidekt.com/decks/6434579/banana (owner: swebb).
#
# Kibo gives every player a Banana token at each upkeep and gets +2/+2 for each
# Banana sacrificed, so the deck's own artifact removal doubles as a pump engine:
# Gorilla Shaman, Gearbane Orangutan, Vandalblast and Bane of Progress all eat
# the table's mana rocks AND the Bananas nobody cashed in. Hardened Scales and
# Primal Vigor turn the +2/+2 into something larger; Rhythm of the Wild and
# Saryth keep the Apes alive through the removal that follows.
#
# Imported as-is apart from printings — the Archidekt list's own printings were
# dropped so the local preference profile picks the art.
