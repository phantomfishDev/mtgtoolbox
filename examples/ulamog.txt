# Name: The Ceaseless Hunger
# Owner: Drew
# Colorless Eldrazi — Ulamog, the Ceaseless Hunger. Eat their library, not their life.
#
# Ulamog reads: "When you cast this spell, exile two target permanents.
# Indestructible. Whenever Ulamog attacks, defending player exiles the top
# twenty cards of their library."
#
# 1. It is EXILE, not mill. Anything that counts graveyards (Keening Stone,
#    Bruvac-style doublers) gets nothing from Ulamog. Exile instead feeds the
#    processors — Blight Herder, Ulamog's Despoiler, Ruin Processor — which
#    are blank cards in most decks and premium ones in this.
#
# 2. The central loophole is Echoes of Eternity. Every triggered ability of a
#    colorless permanent or spell triggers twice, and every card in this deck
#    is colorless. Ulamog's attack becomes FORTY cards. His cast trigger
#    exiles FOUR permanents. Mindcrank mills double, Altar of the Brood mills
#    double, Oblivion Sower exiles eight. It also copies every colorless spell you
#    cast, so Skittering Invasion makes ten Spawn.
#
# 3. Twenty cards hits ONE player. Four-player library-out is ~240 cards, so
#    the deck needs more attackers wearing Ulamog's text: Helm of the Host
#    makes a hasty non-legendary Ulamog every combat, and each copy exiles
#    twenty from whoever it attacks.
#
# 4. Indestructible does not stop sacrifice. Altar of Dementia can sacrifice
#    Ulamog himself: mill ten, send him to the command zone, recast for two
#    more exiled permanents. Each recast costs {2} more — do it once, not as a
#    plan.
#
# 5. Ten mana is the real cost. Fifteen rocks and ramp creatures, the Locus
#    lands and Eldrazi Temple/Eye of Ugin exist to cast him on turn five or six.
#    Eye of Ugin and It That Heralds the End discount the whole top end.
#
# ---------------------------------------------------------------------------
# THE CARDS THAT CARRY IT
# ---------------------------------------------------------------------------
#
# S tier
#   Echoes of Eternity .... doubles Ulamog. See rule 2. Protect it.
#   Helm of the Host ...... a hasty, non-legendary Ulamog token every combat.
#                           Tokens are not cast, so no exile-two — but every
#                           one attacks for twenty more cards. The fastest
#                           clock in the deck.
#   Mindcrank ............. 10 damage from Ulamog is 10 more cards. Every
#                           Fleshraker ping is a card. Doubled by Echoes.
#   Strionic Resonator .... {2}: copy Ulamog's attack trigger. Twenty more
#                           cards for two mana, every turn. Copy the cast
#                           trigger instead and exile two more permanents.
#   Lithoform Engine ...... a second Resonator: {2} copies any triggered
#                           ability, so the Defiler's half-library cast
#                           trigger can hit a second opponent.
#
# A tier
#   Ulamog, the Defiler ... exiles HALF a library on cast, then grows off the
#                           biggest card in exile — which Ulamog just put
#                           there. Annihilator X follows.
#   Altar of Dementia ..... sacrifice a 10/10 Dreadsire or Desolation Twin
#                           token: mill ten. Spawn are free fodder for mana
#                           instead.
#   Altar of the Brood .... every Spawn, Scion, rock and land mills each
#                           opponent one. Skittering Invasion with Echoes is
#                           ten cards from all of them.
#   Skullclamp ............ a 0/1 Spawn plus Skullclamp is draw two for {1}.
#                           The deck's real card-advantage engine.
#   Processors ............ Blight Herder (three Scions), Ulamog's Despoiler
#                           (a 9/9 for six), Ruin Processor (five life). After
#                           one Ulamog attack they never miss.
#   Sands of Delirium ..... the mana sink for Cloudpost turns: X, mill X.
#
# ---------------------------------------------------------------------------
# TRAPS — popular around Ulamog, wrong for this list
# ---------------------------------------------------------------------------
#
#   Keening Stone ......... counts the GRAVEYARD. Ulamog exiles. See rule 1.
#   Mesmeric Orb .......... mills you too, and you untap more than they do.
#   Myriad Landscape ...... fetches two basics that SHARE A LAND TYPE. Wastes
#                           have no land type, so it fetches nothing here.
#   Arcane Signet, Command Tower
#                           make a colour in your commander's identity. A
#                           colorless commander has none: they tap for nothing.
#   Jeweled Lotus ......... banned. Ancient Tomb is a Game Changer, which this
#                           bracket-2 build allows none of.
#   Crumbling Sanctuary ... see OPTIONS. Not a trap, but it switches Mindcrank
#                           off (no life is lost) and it exiles YOUR library
#                           when you take damage too.
#
# ---------------------------------------------------------------------------
# HOW IT PLAYS
# ---------------------------------------------------------------------------
#
#   Turns 1-3   Rocks, Fleshraker, Altar of the Brood, Mindcrank. Thought-Knot
#               Seer on four exiles their best card — processor fuel.
#   Turns 5-6   Ulamog. Exile their two best permanents on cast. Equip
#               Prowler's Helm or Greaves and swing at the player with the SMALLEST
#               library, not the biggest threat: one player decked is one
#               player gone.
#   Turns 7+    Echoes, Helm of the Host, processors. Each turn Ulamog and his
#               copies split across players. Altar of Dementia and Sands of
#               Delirium finish whoever is at single digits.
#   The rest    Opponents with eighty-card libraries take four Ulamog hits.
#               Annihilator from the Defiler, Void Winnower, and simple
#               10/10 beats, close out the last player when exile is slower.
#
#   The weakness: Ulamog is the clock. Exile removal and tuck answer him for
#   good unless you recast (tax). Not of This World, Eldritch Immunity and
#   the shroud boots are there for that. Graveyard decks may like being
#   milled — Soul-Guide Lantern, and Ulamog's exile, are the answer.
#
# ---------------------------------------------------------------------------
# THE MANABASE
# ---------------------------------------------------------------------------
#
#   36 lands plus fifteen ramp pieces, for a deck whose commander costs ten.
#   Every land makes {C}. Cloudpost/Glimmerpost/Vesuva/Thespian's Stage scale
#   together; Eldrazi Temple, Eye of Ugin and Shrine of the Forsaken Gods pay
#   for Eldrazi specifically. Mikokoro and Geier Reach Sanitarium make every
#   player draw — which only speeds up a player you are already decking.
#
# ---------------------------------------------------------------------------
# OPTIONS — swap packages, pick by what the table is like
# ---------------------------------------------------------------------------
#
#   Pure library-out (all damage becomes exile)
#     IN  Crumbling Sanctuary, Tower of Murmurs, Grindclock, Helm of Obedience
#     OUT Mindcrank, Glaring Fleshraker, Reality Smasher, Sword of Body and Mind
#     Sanctuary turns every point of damage into cards exiled from the top —
#     Ulamog's attack becomes 30 cards, 60 with Echoes. It is symmetric, so
#     your library takes their hits too, and it switches Mindcrank off.
#
#   Annihilator / combat finish (faster, meaner)
#     IN  Ulamog's Crusher, Pathrazer of Ulamog, Eldrazi Conscription,
#         Flayer of Loyalties
#     OUT Sands of Delirium, Ruin Processor, Altar of the Brood, Idol of
#         False Gods
#
#   Bracket 3 (up to three Game Changers)
#     IN  Ancient Tomb, Mishra's Workshop, The One Ring
#     OUT Crystal Vein, Sea Gate Wreckage, Dreamstone Hedron
#
